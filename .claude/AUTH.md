# Auth & Permissions

## Roles
super_admin · org_owner · manager · org_member

## Super admin
- Identity stored in Apps Script only — never in frontend
- Approves/denies org owners · manages all orgs and users
- Only role that can change member_limit

## Org owner
- Requires super admin approval before access (shows pending screen until approved)
- Connects own Google Sheet as inventory source
- Full access: all locations · all inventory · all alerts · full activity log
- Can: manage locations · generate/revoke invites · remove members · change org name + sheet source

## Manager
- Joined via invite link (no approval needed)
- Assigned to 1+ locations by org owner
- Can: add/edit/remove inventory in assigned locations · view alerts + activity log for assigned locations
- Can: assign member locations within their locations · generate invites · remove members in their locations
- Cannot: see unassigned locations · change org settings

## Org member
- Joined via invite link (no approval needed)
- Primary location + optional additional active locations (floater scenario)
- Shows location selector at top if multiple active locations assigned
- Can: scan · add · edit quantities · remove inventory in current location only
- Cannot: see other locations · view alerts or activity log · invite others

## Invite links
- Generated by org_owner or manager
- Role set at generation time (manager or org_member)
- Multi-use up to member_limit · expires 7 days · revocable anytime
- Apps Script validates: token + expiry + seat count on every use

## Member limit
- Set by super admin only · stored in organizations.member_limit
- Org owner sees seats used vs limit (read only)
- Invite flow checks count vs limit before allowing join

## Apps Script is source of truth
- Every login sends email → Apps Script returns role + org_id + sheet_id + assigned location_ids
- Frontend renders only what Apps Script returns — never infer or self-assign role
